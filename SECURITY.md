# Security and scope

This is a safe, offline educational evaluation tool, **not** a security product, LLM validator, truth detector or real agent access gate.

- All examples use fictional data and locally defined deterministic rubrics.
- No models, customer records, accounts, external APIs, telemetry, credentials or live execution.
- Any permitted citation token is a *string in a sample fixture*, not proof of provenance or source authenticity.
- Browser results use text-only DOM construction; never evaluate untrusted user input as scripts.
- CLI input is bounded and structural rules are checked before evaluation.
- `CHECKS_PASS` never proves semantic quality, compliance, factual correctness or freedom from prompt injection.

Report a sensitive vulnerability through GitHub private vulnerability reporting if enabled; do not post secrets in public issues.
